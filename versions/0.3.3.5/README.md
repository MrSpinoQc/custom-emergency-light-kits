# CELK 0.3.3.5 · Sadler V05 R4

Préversion FiveM du Sadler V05 R4. Le runtime conserve le numéro interne `0.3.3-socle.8`. Le menu J déclare `0.3.3.5-socle.1`.

- Cabochons noirs au repos sur les montages articulé et fixe.
- Motif **Double flèche** avec pause, reprise et extinction au repli.
- Trois variantes préservées au réimport.

Les 63 fichiers du lot jeu correspondent à l’arborescence qualifiée avec le ZIP Atelier d’origine. Les contrôles GTA ont porté sur le menu CELK intégré. L’essai à deux clients est reporté.
