# CELK 0.3.3.1 (Interface)

Préversion FiveM par Spino. Le lecteur des ensembles de jeu conserve son identifiant de compatibilité `0.3.3-sadler.1`. La révision des menus est `0.3.3.1`.

- **J** regroupe le volet, le motif et les éclairages du Sadler. Le panneau reste ouvert pendant les réglages du volet. Les autres montages présentent leurs séquences et projecteurs.
- **F6** distingue le montage installé et les montages disponibles.
- **F10** ouvre la gestion facultative des packs. Le tableau distingue le pack actif du choix au redémarrage. L’administration exige le droit serveur `celk.admin.packs`.
- Une ressource facultative peut fournir son propre panneau J/F6. Le panneau intégré prend la relève selon la disponibilité du raccord.

Le téléchargement Sadler correspond au profil A de l’Atelier avec diffusion active. Il comprend les variantes Police et Remorqueur. Les empreintes des six ZIP figurent dans [SHA256SUMS.txt](SHA256SUMS.txt).

**Qualification** · 35 contrôles logiciels réussis sur Interface. L’installation du ZIP Sadler exact a été rejouée deux fois depuis les archives livrées, avec la même génération. L’interface 0.3.3.1 n’a pas été essayée en GTA. Les quatre blocs Sadler avaient réussi en GTA solo sur le lecteur précédent. Le test à deux clients reste différé et non validé.
